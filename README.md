# KU Portal — приложения для компьютера и телефона

Приложения портала Kozybayev University. Они открывают тот же сайт [ku-portal.alwaysdata.net](https://ku-portal.alwaysdata.net): те же аккаунты, оценки, расписание, рейтинг, AI-помощник, KU Message, онлайн-экзамен и настройки кабинета. Сайт, программа на компьютере и приложение на телефоне **связаны с одним сервером и базой данных**: что сделано в одном месте — видно в другом.

## 📖 Инструкция для пользователей

### Windows

1. Скачайте [KU-Portal-Setup.exe](https://github.com/SAKEDA-hub/ku-portal-project/releases/latest/download/KU-Portal-Setup.exe) и запустите.
2. Windows может показать синее окно «Система Windows защитила ваш компьютер» — у программы нет платного сертификата. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Выберите папку (можно оставить как есть) → **«Установить»**. На рабочем столе появится ярлык **KU Portal**.
4. Откройте программу и войдите своим аккаунтом портала — тем же, что на сайте.

Без установки: скачайте `KU-Portal-Portable.exe` и просто запускайте его (например, с флешки).
Удаление: «Параметры → Приложения → KU Portal → Удалить».

### macOS

1. Скачайте `.dmg` для своего Mac: Apple Silicon (M1–M4) или Intel. Узнать: меню Apple → «Об этом Mac» → «Чип» / «Процессор».
2. Откройте файл и перетащите **KU Portal** в папку **«Программы»**.
3. Первый запуск: в «Программах» **правый клик по KU Portal → «Открыть» → «Открыть»** (у программы нет подписи Apple, без этого macOS не даст запустить).
   Если macOS пишет, что приложение «повреждено», выполните в Терминале `xattr -cr "/Applications/KU Portal.app"` и откройте снова.

### Linux

```bash
chmod +x KU-Portal-linux.AppImage
./KU-Portal-linux.AppImage
```

Если не запускается из-за FUSE: `sudo apt install libfuse2` (Ubuntu 24.04: `libfuse2t64`) или `./KU-Portal-linux.AppImage --appimage-extract-and-run`.

### Android

1. Откройте на телефоне ссылку [KU-Portal.apk](https://github.com/SAKEDA-hub/ku-portal-project/releases/latest/download/KU-Portal.apk) и скачайте файл.
2. Откройте скачанный файл. Телефон попросит разрешить установку из этого источника (браузера или «Файлов») — **разрешите** и вернитесь назад.
3. **«Установить»**. Google Play Защита может предупредить о неизвестном приложении — **«Всё равно установить»**.
4. Приложение открывает сайт `ku-portal.alwaysdata.net`. В новой установке нажмите **«Сайт портала» → «Подключиться»**; установленная прежняя версия сама заменит адрес Render на новый. Затем войдите аккаунтом KU Portal.
5. Уведомления (новые оценки, изменения расписания, открытие экзамена, вызов на speaking): в портале **«Кабинет» → «Уведомления»** включите их и разрешите, когда телефон спросит.

Сменить сервер: на главной нажмите «Назад» → **«Сменить сервер»**.

### iPhone

Отдельного приложения для iPhone нет: для этого Apple требует Mac и платный аккаунт разработчика. Портал можно добавить на экран «Домой» — он будет открываться как приложение:
откройте [ku-portal.alwaysdata.net](https://ku-portal.alwaysdata.net) в **Safari** → **«Поделиться»** → **«На экран Домой»** → «Добавить».

### Как пользоваться

Внутри — тот же портал, что на сайте:
- **Главная** — виджеты, расписание, сервисы (рейтинг, успеваемость, AI-помощник и др.);
- **KU Message** — открывается из портала с тем же аккаунтом, отдельная регистрация не нужна;
- **Экзамен** → «Перейти к онлайн-экзамену» — онлайн-экзамен (тесты, writing, speaking). Вход передаётся из KU Portal, отдельный пароль не нужен. Вернуться — кнопка **«KU Portal»** вверху слева;
- **Кабинет** — профиль и все настройки: тема и цвет, язык (RU / KZ / EN), уведомления, пароль, двухфакторная защита, сеансы, скачивание своих данных.

На компьютере есть меню: **Вид → Назад / Вперёд / Обновить / Масштаб**, **Справка → Открыть портал в браузере**. Скачанные файлы (экспорт данных, ведомость CSV) сохраняются через обычное окно «Сохранить».

### Первое открытие идёт долго?

При первом открытии приложению нужен интернет, чтобы подключиться к сайту. На экране подключения по умолчанию выбран `ku-portal.alwaysdata.net`; отдельная база внутри приложения не создаётся.

### Обновление

- **Компьютер**: скачайте установщик по той же ссылке и установите поверх. Аккаунт и данные хранятся на сайте — ничего не потеряется.
- **Android**: скачайте APK по той же ссылке и установите. Если телефон пишет «Приложение не установлено» или «конфликт с существующим пакетом» — удалите старую версию KU Portal и установите новую (данные на сайте сохранятся). Чтобы обновления всегда ставились поверх, владельцу репозитория нужно один раз настроить [постоянный ключ подписи](#постоянный-ключ-подписи-android).

### Если что-то не работает

| Проблема | Что сделать |
|---|---|
| «Не удалось открыть портал» | Проверьте интернет и нажмите «Повторить». При медленном соединении подождите несколько секунд. |
| AI-помощник пишет, что модель недоступна | Модель Gemma подключается к серверу сайта отдельно (LM Studio) — это настраивает владелец сайта, см. [ku-portal](https://github.com/SAKEDA-hub/ku-portal). Остальной портал работает. |
| Не приходят уведомления на Android | «Кабинет» → «Уведомления» → включить; настройки Android → Приложения → KU Portal → Уведомления → разрешить. Уведомления приходят, пока приложение открыто или свёрнуто. |
| Текст слишком мелкий или крупный | В портале: «Кабинет» → «Оформление» → «Размер текста»; в онлайн-экзамене — шестерёнка/аватар → «Размер текста». Системный размер шрифта Android приложение не применяет, чтобы кнопки не налезали друг на друга. |
| Windows не даёт запустить | «Подробнее» → «Выполнить в любом случае». |
| Mac: «приложение повреждено» | `xattr -cr "/Applications/KU Portal.app"` в Терминале. |

## ⚙️ Дополнительно: портал без интернета (только компьютер)

В программе для компьютера есть **встроенный сервер** — тот же портал, запущенный прямо на ПК. Он нужен, если нет интернета или хочется подключить свою модель AI. **Внимание:** у встроенного сервера свои аккаунты и данные, с сайтом они не связаны.

1. **Файл → Настройки приложения** (`Ctrl+,`) → «Откуда брать портал» → **«Встроенный сервер»** → «Сохранить» → «Перезапустить сейчас».
2. При первом запуске создаются отдельные локальные демо-аккаунты со случайными паролями. Их учётные данные сохраняются в `demo-credentials.json` внутри защищённой папки данных; эта база не совпадает с сайтом. Онлайн-экзамен открывается через вход KU Portal.
3. **AI-помощник**: установите [LM Studio](https://lmstudio.ai), загрузите модель Gemma (`google/gemma-4-e4b` или похожую), **Developer → Start Server**. В настройках программы адрес уже стоит `http://localhost:1234` → «Проверить подключение».
4. **Телефон к компьютеру** (одна сеть Wi-Fi): адрес вида `http://192.168.1.10:3000` показан в настройках программы и в **Справка → Телефон**. В приложении на телефоне: «Сменить сервер» → «Компьютер с KU Portal Desktop» → ввести адрес. Если Windows спросит про брандмауэр — разрешите доступ в частных сетях.
5. Данные встроенного сервера: **Файл → Открыть папку с данными** (не удаляются при обновлении программы). Журнал: **Файл → Открыть журнал сервера**.

Вернуться к сайту: «Откуда брать портал» → «Сайт портала».

## 🛠 Для разработчиков

### Устройство репозитория

| Папка | Что внутри |
|---|---|
| `app/` | Исходники сайта из [ku-portal](https://github.com/SAKEDA-hub/ku-portal) — **без изменений** (проверяется тестом). Нужны для встроенного сервера. Обновить: `./scripts/sync-app.sh ../ku-portal` |
| `desktop/` | Программа для компьютера (Electron): `main.js` — окна, меню, безопасность, встроенный сервер; `config.js` — настройки; `ui/` — экраны настроек, ожидания и ошибки; `ui/app-fix.css` — поправки раскладки для узких экранов (общие с Android; после правки — `python3 scripts/sync-app-fix.py`) |
| `mobile/android/` | Приложение для Android: `MainActivity.java`, `WebBridge.java`; `assets/ui/` — экран подключения; `assets/bridge.js` — системные уведомления, сохранение и выбор файлов |
| `tests/` | `node --test tests/*.test.js` — настройки, встроенный сервер, главный процесс (на заглушке Electron) |
| `.github/workflows/build.yml` | Проверки → сборка Windows / macOS / Linux / Android → публикация в Releases |

### Как выходит новая версия

Достаточно `git push` в ветку `main`. GitHub Actions проверит код, соберёт все файлы (около 5 минут) и опубликует релиз `v1.0.<номер сборки>` здесь и в публичном [ku-portal-project](https://github.com/SAKEDA-hub/ku-portal-project) — ссылки «Скачать» ведут туда. Для публикации в ku-portal-project нужен секрет `RELEASES_TOKEN` (fine-grained токен с правом Contents: Read and write на ku-portal-project); без него релиз появится только здесь. Ход сборки — вкладка **Actions**; журналы каждой части сохраняются ещё и в служебные ветки `ci/*` (их можно не трогать).

Вручную: Actions → Build → **Run workflow**. Свой номер версии: `git tag v2.0.0 && git push origin v2.0.0`.

### Запуск из исходников

```bash
# компьютер (Node.js 18+)
cd desktop && npm install && npm start
npm run dist                       # установщик для текущей ОС → desktop/dist/

# Android (JDK 17 + Android SDK; проще — Android Studio: File → Open → mobile/android)
cd mobile/android && ./gradlew assembleRelease
```

### Постоянный ключ подписи (Android)

Сейчас каждый APK подписывается временным ключом сборки, поэтому новая версия ставится только после удаления старой. Чтобы обновления ставились поверх, один раз:

1. Создайте ключ (`keytool` есть в JDK и в Android Studio: `…/Android Studio/jbr/bin/keytool`):
   ```bash
   keytool -genkeypair -v -keystore ku.jks -alias ku -keyalg RSA -keysize 2048 -validity 10000
   ```
   Запомните пароль. Файл `ku.jks` храните у себя и **никогда не загружайте в репозиторий**.
2. Получите его текст в base64: macOS/Linux — `base64 -i ku.jks | tr -d '\n'`, Windows (PowerShell) — `[Convert]::ToBase64String([IO.File]::ReadAllBytes("ku.jks"))`.
3. На GitHub: **Settings → Secrets and variables → Actions → New repository secret** — четыре секрета:
   `ANDROID_KEYSTORE_BASE64` (текст из шага 2), `ANDROID_KEYSTORE_PASSWORD` (пароль), `ANDROID_KEY_ALIAS` (`ku`), `ANDROID_KEY_PASSWORD` (тот же пароль).
4. Запустите сборку (Actions → Build → Run workflow). Пользователям последний раз нужно удалить старое приложение — дальше обновления ставятся поверх.
