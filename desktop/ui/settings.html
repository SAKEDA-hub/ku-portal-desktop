Телефон и компьютер должны быть в одной сети Wi-Fi. Если Windows спросит про брандмауэр — разрешите доступ в частных сетях.

AI-помощник (LM Studio)

Ответы составляет модель Gemma, запущенная в LM Studio, по локальной базе материалов университета (1 565 фрагментов). В LM Studio: загрузите модель → Developer → Start Server.

LM Studio на этом ПК — http://localhost:1234. На другом ПК в сети — http://192.168.x.x:1234 (в LM Studio включите «Serve on Local Network»), через Tailscale — http://100.x.x.x:1234, через туннель — https://….
Если точного совпадения нет, берётся похожая загруженная модель.
